# Rajiv Gandhi Mahavidyalaya, Jagdishpur, Amethi (U.P.) - Official Website

A responsive, high-performance website created for **Rajiv Gandhi Mahavidyalaya (राजीव गाँधी महाविद्यालय जगदीशपुर अमेठी)**. Built using pure **HTML5, CSS3, and JavaScript (ES6+)** without external frameworks, build tools, databases, or runtime dependencies.

Completely mobile-responsive, SEO-optimized, and ready for instant deployment on **GitHub Pages**, Vercel, or Netlify.

## 🌐 Deploy to GitHub Pages (Under 2 Minutes)

1. **Commit your project:**
   ```bash
   git init
   git add .
   git commit -m "Official Rajiv Gandhi Mahavidyalaya website"
   ```

2. **Push to GitHub repository:**
   ```bash
   git remote add origin https://github.com/<your-username>/rajiv-gandhi-mahavidyalaya.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - In your repository, click **Settings** &rarr; **Pages**.
   - Under **Build and deployment > Source**, choose **Deploy from a branch**.
   - Set **Branch** to `main` and folder to `/ (root)`, then click **Save**.
   - Your site will be published at:  
     `https://<your-username>.github.io/rajiv-gandhi-mahavidyalaya/`
